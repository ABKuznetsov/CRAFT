# CRAFT

**CRAFT — Crystal Research and Analysis Framework Toolkit** is a desktop application for viewing and analysing crystal structures from CIF files.

## What it does

- interactive 3D view of atoms, bonds and coordination polyhedra;
- recognition of coordination environments, structural units and motifs;
- analysis of connected components and periodic dimensionality;
- chemistry-aware validation of the structural model;
- export of figures, tables and analysis results.

[Open the visual guide](https://abkuznetsov.github.io/CRAFT/) to see the real CRAFT interface and worked examples for CaMoO₄, LiB₃O₅, FeS₂ and anorthite.

## Download

[Download `CRAFT_Windows_1.1.1_Setup.exe`](https://github.com/ABKuznetsov/CRAFT/releases/download/v1.1.1/CRAFT_Windows_1.1.1_Setup.exe)

The Windows installer includes everything required to launch CRAFT.

## Run from source

```bash
git clone https://github.com/ABKuznetsov/CRAFT.git
cd CRAFT
run_craft.bat
```

Python 3.11 or 3.12 is required.
